단위: 연봉(만원) · 직급별 Min/Mid/Max를 막대로 보여줍니다. 연도·월·직종·직무를 좁혀서 볼 수 있고, 아래 비교 기준에서 여러 값을 선택하면 나란히 비교할 수 있습니다(최대 4개). 막대를 클릭하면 아래에 실제 데이터가 펼쳐집니다. 값을 전부 한 화면에서 비교하고 싶다면 우측 상단의 "표로 보기"를 눌러주세요 — 표는 개수 제한 없이 직급 × 전체 값을 매트릭스로 보여줍니다.
비교 기준 직급만 월별 비교 직종별 비교 직무별 비교
